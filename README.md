# ¡VOTA! — A1 Me gusta / No me gusta

Ta paczka jest już skonfigurowana z projektem Firebase `me-gusta-siliciumra`.

## Pliki
- `profesor.html` — panel nauczyciela
- `alumno.html` — ekran ucznia
- `questions.js` — 20 pytań, odpowiedzi i losowe nicki
- `firebase-config.js` — gotowa konfiguracja Firebase
- `database.rules.json` — kopia reguł bezpieczeństwa

## Co jeszcze trzeba zrobić
1. Wrzuć wszystkie pliki do jednego folderu/repozytorium na GitHub.
2. Włącz GitHub Pages dla tego repozytorium.
3. Otwórz publiczny adres `profesor.html`.
4. Utwórz klasę.
5. Otwórz link ucznia na drugim urządzeniu/przeglądarce i wykonaj test głosu.

Nie uruchamiaj plików przez podwójne kliknięcie jako `file://` — moduły JavaScript powinny być serwowane przez stronę WWW, np. GitHub Pages.
